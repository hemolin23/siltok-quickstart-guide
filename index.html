第一次使用，请按顺序操作

照着 4 步，
开始用 Siltok。

不用自己配置网络，也不用记任何命令。请从第 1 步开始，完成一项再进行下一项。

  1. 1选择电脑并下载点击下方“开始第 1 步”，选择 Windows 或 macOS，下载安装包。
  2. 2安装并打开 DashWindows 双击运行；Mac 打开 DMG，将 Siltok Dash 拖进“应用程序”。
  3. 3向运营人员要连接信息告诉运营人员你已经打开软件，获取本次测试的 IP 地址和端口。
  4. 4填写信息并确认模型在“新增主机”或“设置—服务连接”中填写，连接成功后打开控制台；看到模型列表就完成了。

05
排查问题

遇到问题先看这里

从哪里获取 IP 地址和端口？

请联系运营人员获取本次测试的有效配置。为避免泄露与使用过期信息，公开页面不展示具体地址和端口。

Dash 测试连接失败

核对运营人员提供的 IP 地址和端口，确保填写准确且前后没有空格；仍无法连接时请保存错误截图并联系运营人员。

页面中没有模型

刷新或重启 Dash；仍没有模型时联系管理员确认服务状态和账号权限。

点击生成后任务失败

保存错误提示、控制台信息和操作系统版本，并说明所选模型与操作步骤后联系管理员。

macOS 下载后无法打开软件

先确认安装包来自本页面。可以打开 Mac 上的 Codex，把 DMG 安装包拖入对话并发送：“这是公司提供的 Siltok Dash 安装包，请帮我检查并打开安装程序；如需系统授权，请告诉我具体操作。”请按 Codex 提示完成操作，不要关闭 macOS 的系统安全保护；仍无法打开时联系运营人员。

微信里不能下载安装包

请复制本页地址到 Chrome、Edge 或 Safari 打开，再点击下载按钮。

需要帮助？

联系 Siltok 管理员

请同时提供错误截图、设备名称、操作系统版本和你执行到的步骤。任选一位管理员，使用企业微信扫码添加。
