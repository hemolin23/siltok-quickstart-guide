02
安装并打开

把 Siltok Dash 打开

只看与你电脑对应的一栏。

Windows

运行 Windows 安装程序

  1. 打开电脑的“下载”文件夹。
  2. 双击 siltok-dash-2026092803-windows-x64-setup.exe。
  3. 若出现用户账户控制提示，核对文件来自本页面后点击“是”。
  4. 按照安装向导点击“下一步”和“安装”。
  5. 安装完成后，从桌面或开始菜单打开 Siltok Dash。
macOS

打开 DMG 文件

  1. 打开电脑的“下载”文件夹。
  2. 双击 Siltok.Dash-0.1.1-arm64.dmg。
  3. 将 Siltok Dash 拖进“应用程序”。
  4. 从“应用程序”中打开 Siltok Dash。
Mac 打不开？把 DMG 拖进 Codex，对它说：“这是公司提供的 Siltok Dash，请帮我检查并打开；如需系统授权，请告诉我怎么操作。”
本步完成标志你已经看到 Siltok Dash 主页面。
03
获取连接信息

添加运营人员企业微信

任选一位扫码添加，发送：“我已经打开 Siltok Dash，请发我本次测试的 IP 地址和端口。”连接信息不会在公开网页展示。

本步完成标志运营人员已经把 IP 地址和端口发给你。

06
排查问题

遇到问题先看这里

从哪里获取 IP 地址和端口？

请联系运营人员获取本次测试的有效配置。为避免泄露与使用过期信息，公开页面不展示具体地址和端口。

Dash 测试连接失败

核对运营人员提供的 IP 地址和端口，确保填写准确且前后没有空格；仍无法连接时请保存错误截图并联系运营人员。

页面中没有模型

刷新或重启 Dash；仍没有模型时联系管理员确认服务状态和账号权限。

点击生成后任务失败

保存错误提示、控制台信息和操作系统版本，并说明所选模型与操作步骤后联系管理员。

macOS 下载后无法打开软件

先确认安装包来自本页面。可以打开 Mac 上的 Codex，把 DMG 安装包拖入对话并发送：“这是公司提供的 Siltok Dash 安装包，请帮我检查并打开安装程序；如需系统授权，请告诉我具体操作。”请按 Codex 提示完成操作，不要关闭 macOS 的系统安全保护；仍无法打开时联系运营人员。

微信里不能下载安装包

请复制本页地址到 Chrome、Edge 或 Safari 打开，再点击下载按钮。
